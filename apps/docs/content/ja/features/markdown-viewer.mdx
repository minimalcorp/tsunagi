# Markdown Viewer

ローカルの Markdown ファイルを GitHub Flavored Markdown として表示します。手順書の `- [ ]` をクリックすると、元ファイルの `[ ]` / `[x]` が書き換わります。Claude Code / Codex が手順書を書き出すと、タスク詳細のタブとして自動で開きます。

## 開き方

| 方法                | 内容                                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| タスク詳細のタブ    | タブ列の <kbd>FileText</kbd> ボタンから、worktree 内の .md（更新が新しい順）を選ぶか、絶対パスを入力する |
| Claude Code / Codex | 手順書を書き出すと MCP ツール `tsunagi_open_markdown` でタブを開き、URL も提示する                       |
| 単体ページ          | `http://localhost:2791/markdown-viewer?path=<URL エンコードした絶対パス>`                                |

`path` を省略した単体ページでは、パス入力と最近開いたファイルを表示します。

<Callout type="info">
  エージェントが開いたタブは、表示中のタブを切り替えずに未読ドット付きで追加されます。同じファイルのタブがあれば再利用します。
</Callout>

## 表示できるもの

- タスクリスト（チェックで書き戻し。完了項目は薄く取り消し線）、見出しごとの目次と進捗
- 表・コード・脚注など GFM の記法
- alert: `> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]`
- mermaid 図（下記の操作でパン・ズーム）
- 相対リンク: `.md` は Viewer で開き、画像（png / jpg / gif / webp / svg）は表示する

ファイルが外部で変更されると自動で再表示します。開いた後に他で変更されたファイルへのチェックは保存せず、最新を読み込み直します。

## mermaid の操作

図をクリックすると操作中になります（枠が強調表示）。Esc か図の外をクリックで解除します。

| 操作                          | 内容                         |
| ----------------------------- | ---------------------------- |
| ピンチ / ⌘・Ctrl + スクロール | 拡大縮小（操作中でなくても） |
| 二本指スワイプ                | 移動（操作中のみ）           |
| ドラッグ                      | 移動                         |
| ⇧1 / ⇧0                       | 全体表示 / 100%              |
| ⌘・Ctrl + `+` / `-`           | 拡大 / 縮小                  |
| ダブルクリック                | 全体表示                     |

## 制約

- 読み書きできるのは `.md` / `.markdown` の絶対パスのみ（5MB まで）
- [外部からの利用](/ja/features/remote-access/) で公開している場合も、Basic 認証を通過すれば同じように使えます

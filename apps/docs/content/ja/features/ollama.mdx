# Ollama

[ローカルLLM（実験的機能）](/ja/features/local-llm/) のプロバイダーとして [Ollama](https://ollama.com) を使えます。

## セットアップ

Ollama のインストール・モデルの pull・起動はご自身で行ってください。

1. Ollama v0.14.0 以降をインストールする（公式アプリ、または `brew install ollama`）
2. モデルを pull する（例: `ollama pull qwen3.6:35b-a3b-coding-nvfp4`。[推奨モデル](/ja/features/local-llm/#推奨モデル)）
3. 設定画面（Global）の **Ollama** で有効化する
4. **Claude Code のローカルLLM (実験的機能)** で Ollama のモデルを選んで保存する

設定画面の Ollama 欄には、接続状態・バージョン・読み込み中のモデルが表示されます。Base URL（既定 `http://localhost:11434`、Docker では `host.docker.internal`）は詳細設定で変更できます。

## コンテキスト長

Ollama の Anthropic 互換 API ではリクエスト毎にコンテキスト長を指定できず、Ollama 全体の既定値（VRAM 24GiB 未満は 4k、24〜48GiB は 32k、48GiB 以上は 256k）が使われます。そのため Tsunagi は、設定したコンテキスト長を固定した派生モデル（`<モデル>-tsunagi-ctx<長さ>`）を作成して使います。重みは元のモデルと共有されるため、ディスクは増えません。

## WebSearch を ollama.com で代行する

「Claude Code のローカルLLM」欄の WebSearch を「ollama.com」にし、使用中のモデルが Ollama の場合、Claude Code の WebSearch を Ollama が ollama.com の Web 検索 API で代行します。

- Ollama を動かしているマシンで `ollama signin` が必要です（Ollama 欄でサインイン状態を確認できます）
- 未サインインだと `Web search error: unavailable` になります
- 検索クエリは ollama.com に送信されます
- `OLLAMA_NO_CLOUD=1`（またはアプリの設定でクラウドを無効化）していると使えません

既定の「ローカル検索（SearXNG）」なら、サインインなしでローカルで検索できます（[ローカル検索](/ja/features/local-search/)）。

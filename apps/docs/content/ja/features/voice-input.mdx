# 音声入力（mukuchi）

Tsunagi 自体は音声入力の機能を持ちません。音声入力には、同じく minimalcorp が公開している [mukuchi](https://mukuchi.minimalcorp.com/) を使います。

mukuchi は常駐型の音声入力アプリです。話した区間だけを端末内で文字起こしし、前面のアプリのカーソル位置に入力します。ブラウザで開いた Tsunagi のタブ（Claude Code / Codex のターミナル）にも、そのまま入力できます。

- **対応 OS**: macOS（Apple Silicon、macOS 13 以降）/ Windows 11（x64）。Linux は準備中
- **料金**: 無料・アカウント登録不要
- **ショートカット**: Mac は `⌥Space`、Windows は `Alt+Space`（既定）

ダウンロードは [mukuchi の公式サイト](https://mukuchi.minimalcorp.com/) から行えます。

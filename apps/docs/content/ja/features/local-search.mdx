# ローカル検索（実験的機能）

Claude Code の WebSearch は Anthropic のサーバーツールのため、[ローカルLLM](/ja/features/local-llm/) のタブではそのままでは使えません（LM Studio は無視し、Ollama は ollama.com へのサインインが必要）。ローカル検索を使うタブでは WebSearch を無効化し、Tsunagi の MCP が提供する `web_search` ツールで、ホスト上の [SearXNG](https://docs.searxng.org/) に検索させます。

## セットアップ

Tsunagi は SearXNG を次のどちらかで起動します。設定画面の **ローカル検索 (SearXNG)** に、Tsunagi が使う（使った）起動方法が表示されます。

| 起動方法      | 条件                               | 動作                                                                 |
| ------------- | ---------------------------------- | -------------------------------------------------------------------- |
| `searxng-run` | PATH（または指定パス）にある       | 子プロセスとして起動する                                             |
| Docker        | `searxng-run` がなく Docker がある | コンテナ（既定名 `searxng`）を起動する。無ければ作成してから起動する |

既定（自動）では `searxng-run` を優先します。詳細設定の **起動方法** で固定することもできます。

### Docker で起動する

[Docker Desktop](https://www.docker.com/products/docker-desktop/) を起動しておけば、追加の作業は不要です。コンテナが無い場合、Tsunagi が [公式イメージ](https://docs.searxng.org/admin/installation-docker.html) を取得し、次の内容でコンテナを作成します（初回はイメージの取得に数分かかります）。

- ポート: `127.0.0.1:7964`（詳細設定のポート）→ コンテナの `8080`
- 設定ファイル: `~/.tsunagi/searxng/docker/<コンテナ名>/config/settings.yml`（JSON 形式の結果を有効化済み）

自分で作成したコンテナを使う場合は、詳細設定の **Docker のコンテナ名** に指定してください。Tsunagi のポートで公開し、`settings.yml` の `search.formats` に `json` を含めておく必要があります。

```yaml
search:
  formats:
    - html
    - json
```

### searxng-run で起動する

`searxng-run` が PATH にあれば、それ以上の設定は不要です。

```bash
# nix
nix profile install nixpkgs#searxng
```

nix 以外の方法は [SearXNG のインストール方法](https://docs.searxng.org/admin/installation.html) を参照してください。PATH にない場合は、設定画面の詳細設定で `searxng-run` のパスを指定できます。

Tsunagi を Docker で動かしている場合（`make up`）は、コンテナに SearXNG が入っているためインストールは不要です。

## 自動起動・停止

| タイミング                                       | 動作                                    |
| ------------------------------------------------ | --------------------------------------- |
| Tsunagi の起動時・Ollama か LM Studio の有効化時 | SearXNG を起動する（ポート既定 `7964`） |
| Ollama と LM Studio を両方無効にしたとき         | Tsunagi が起動した SearXNG を停止する   |
| Tsunagi の終了時                                 | Tsunagi が起動した SearXNG を停止する   |

- 停止するのは Tsunagi が起動したものだけです（Docker の場合は `docker stop`）。
- ポートで既に SearXNG が応答していれば、それを使います（Tsunagi は停止しません）。
- SearXNG を起動できなくても、Tsunagi 自体は通常どおり起動します。設定画面の **ローカル検索 (SearXNG)** に状態が表示されます。
- `searxng-run` で起動するときは、Tsunagi が生成した設定ファイル（`~/.tsunagi/searxng/settings.yml`、JSON 形式の結果を有効化）を使います。独自の設定ファイルを使う場合は `search.formats` に `json` を含めてください。

## MCP の絞り込み

`ANTHROPIC_BASE_URL` を変えたセッションでは Claude Code の MCP tool search が無効になり、全 MCP のツール定義が毎回プロンプトに載ります。ローカルLLMでは読み込み（prefill）が遅くなり、ツール選択の精度も落ちるため、ローカル検索を使うタブは次の引数で起動します。

- `--strict-mcp-config`: MCP を Tsunagi のタスク管理と `web_search` だけにする
- `--disallowedTools WebSearch`: 組み込み WebSearch を無効化する
- `--append-system-prompt`: Web 検索に `web_search` を使うよう指示する

<Callout type="info">
  SearXNG は Google / Bing / DuckDuckGo
  などの検索エンジンに問い合わせます。短時間に大量に検索すると、検索エンジン側で一時的にブロックされることがあります。
</Callout>

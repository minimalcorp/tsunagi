# Ollama

You can use [Ollama](https://ollama.com) as a provider for
[Local LLM (experimental)](/en/features/local-llm/).

## Setup

You install Ollama, pull models and start the server yourself.

1. Install Ollama v0.14.0 or later (the official app, or `brew install ollama`)
2. Pull a model (e.g. `ollama pull qwen3.6:35b-a3b-coding-nvfp4`; see
   [Recommended models](/en/features/local-llm/#recommended-models))
3. Enable **Ollama** in Tsunagi's settings (Global)
4. Pick an Ollama model under **Claude Code のローカルLLM (実験的機能)** and save

The Ollama section shows the connection status, version and loaded models.
You can change the Base URL (default `http://localhost:11434`,
`host.docker.internal` in Docker) in the advanced settings.

## Context length

Ollama's Anthropic-compatible API cannot take a context length per
request, so Ollama's global default is used (4k below 24 GiB of VRAM, 32k
for 24–48 GiB, 256k for 48 GiB or more). Tsunagi therefore creates a
derived model with the configured context length baked in
(`<model>-tsunagi-ctx<length>`) and uses it. It shares the weights with the
original model, so it takes no extra disk space.

## WebSearch via ollama.com

If you set WebSearch to "ollama.com" under "Claude Code のローカルLLM" and the model in use
is an Ollama model, Ollama runs Claude Code's WebSearch through
ollama.com's web search API.

- Requires `ollama signin` on the machine running Ollama (the Ollama
  section shows the sign-in status)
- Without sign-in, WebSearch fails with `Web search error: unavailable`
- Queries are sent to ollama.com
- Not available with `OLLAMA_NO_CLOUD=1` (or cloud disabled in the app)

The default "local search (SearXNG)" searches locally without signing in
(see [Local search](/en/features/local-search/)).

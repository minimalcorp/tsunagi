# Voice Input (mukuchi)

Tsunagi itself has no voice input. For dictation, use [mukuchi](https://mukuchi.minimalcorp.com/), also published by minimalcorp.

mukuchi is a resident voice input app. It transcribes only the segments you speak, on-device, and types the text at the cursor of the foreground app. That includes Tsunagi tabs (Claude Code / Codex terminals) open in your browser.

- **Supported OS**: macOS (Apple Silicon, macOS 13+) / Windows 11 (x64). Linux is in preparation
- **Price**: free, no account required
- **Shortcut**: `⌥Space` on Mac, `Alt+Space` on Windows (default)

Download it from the [mukuchi website](https://mukuchi.minimalcorp.com/).
